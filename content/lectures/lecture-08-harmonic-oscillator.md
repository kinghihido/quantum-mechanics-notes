# 第8章 量子谐振子

> **本章导读**：谐振子是量子力学中最重要的模型之一。任何光滑势能在极小点附近都可以近似为抛物线，因此小振动一律是谐振子。分子振动、晶格振动（声子）、电磁场量子化——这些都建立在谐振子的基础上。量子谐振子有两种解法：解析法（解微分方程）和代数法（升降算符）。后者更优雅，我们将在第21章详细讨论。本章先用解析法求解。

---

## 8.1 谐振子模型

### 8.1.1 势能函数

一维谐振子的势能函数为：

$$V(x) = \frac{1}{2}m\omega^2 x^2$$

其中 $m$ 是粒子质量，$\omega$ 是经典角频率。

这是一个抛物线势阱，极小点在 $x = 0$。

### 8.1.2 为什么谐振子重要？

**泰勒展开论证**：

任何光滑势能 $V(x)$ 在极小点 $x_0$ 附近展开：

$$V(x) = V(x_0) + V'(x_0)(x - x_0) + \frac{1}{2}V''(x_0)(x - x_0)^2 + \cdots$$

由于 $x_0$ 是极小点，$V'(x_0) = 0$，$V''(x_0) > 0$。取 $V(x_0) = 0$（能量零点），定义 $k = V''(x_0)$，则：

$$V(x) \approx \frac{1}{2}k(x - x_0)^2$$

这正是谐振子势，其中 $\omega = \sqrt{k/m}$。

**结论**：任何光滑势能在极小点附近都是谐振子。分子振动、晶格振动、固体中的原子——只要振幅小，都是谐振子。

## 8.2 解析法求解

### 8.2.1 定态薛定谔方程

$$-\frac{\hbar^2}{2m}\phi'' + \frac{1}{2}m\omega^2 x^2 \phi = E\phi$$

引入无量纲变量 $\xi = \sqrt{m\omega/\hbar} \, x$ 和 $\epsilon = 2E/(\hbar\omega)$，方程化为：

$$\frac{d^2\phi}{d\xi^2} + (\epsilon - \xi^2)\phi = 0$$

### 8.2.2 渐近行为

当 $\xi \to \infty$ 时，$\xi^2 \gg \epsilon$，方程近似为：

$$\phi'' \approx \xi^2 \phi$$

解为 $\phi \sim e^{\pm \xi^2/2}$。取衰减支 $e^{-\xi^2/2}$（保证归一化）。

### 8.2.3 级数解

设 $\phi(\xi) = h(\xi) e^{-\xi^2/2}$，代入方程得 $h(\xi)$ 满足：

$$h'' - 2\xi h' + (\epsilon - 1)h = 0$$

设 $h(\xi) = \sum_{j=0}^\infty a_j \xi^j$，代入得递推关系：

$$a_{j+2} = \frac{2j + 1 - \epsilon}{(j+1)(j+2)} a_j$$

### 8.2.4 量子化条件

如果级数无穷延伸，$h(\xi)$ 的增长速度比 $e^{\xi^2}$ 还快，导致 $\phi$ 发散。为避免发散，级数必须在某处截断。

设级数在 $j = n$ 处截断（$a_{n+2} = 0$），则：

$$2n + 1 - \epsilon = 0 \quad \Rightarrow \quad \epsilon = 2n + 1$$

因此：

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega, \quad n = 0, 1, 2, \ldots$$

这就是**谐振子能级**。

### 8.2.5 厄米多项式

截断的级数 $h_n(\xi)$ 是 $n$ 次多项式，叫做**厄米多项式** $H_n(\xi)$。

前几个厄米多项式：

$$H_0(\xi) = 1$$
$$H_1(\xi) = 2\xi$$
$$H_2(\xi) = 4\xi^2 - 2$$
$$H_3(\xi) = 8\xi^3 - 12\xi$$

归一化波函数为：

$$\phi_n(x) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4} \frac{1}{\sqrt{2^n n!}} H_n(\xi) e^{-\xi^2/2}$$

其中 $\xi = \sqrt{m\omega/\hbar} \, x$。

## 8.3 能级与波函数的性质

### 8.3.1 等间距能级

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega$$

能级间距 $\Delta E = \hbar\omega$，与 $n$ 无关。这是谐振子最独特的性质。

**物理意义**：
- 基态能量 $E_0 = \hbar\omega/2$（零点能）
- 激发态能量 $E_n = E_0 + n\hbar\omega$
- 每次"激发"增加一个能量子 $\hbar\omega$

这与电磁场的量子化直接相关：频率为 $\omega$ 的电磁场模式，其能量为 $(n + 1/2)\hbar\omega$，$n$ 是光子数。

### 8.3.2 零点能

$$E_0 = \frac{1}{2}\hbar\omega$$

零点能是不确定关系的直接结果。粒子被限制在势阱中（$\Delta x$ 有限），动量不确定（$\Delta p > 0$），因此动能不为零。

对于谐振子，Virial 定理（见 8.4.3）说动能和势能各占总能量的一半：

$$\langle T \rangle = \langle V \rangle = \frac{E_n}{2} = \frac{1}{2}\left(n + \frac{1}{2}\right)\hbar\omega$$

基态动能 $\langle T \rangle_0 = \hbar\omega/4 > 0$。

### 8.3.3 波函数的节点

第 $n$ 个波函数有 $n$ 个节点（$H_n(\xi)$ 有 $n$ 个零点）。

这与节点定理一致：一维束缚态中，第 $n$ 个能级的波函数恰有 $n-1$ 个节点。注意谐振子的量子数从 $n = 0$ 开始，所以基态（$n = 0$）没有节点，第一激发态（$n = 1$）有一个节点，等等。

### 8.3.4 奇偶性

谐振子势关于 $x = 0$ 对称，波函数有确定的奇偶性：

- $n$ 为偶数：$H_n(\xi)$ 是偶函数，$\phi_n(x)$ 是偶函数
- $n$ 为奇数：$H_n(\xi)$ 是奇函数，$\phi_n(x)$ 是奇函数

---

## 8.4 期望值与 Virial 定理

### 8.4.1 位置和动量的期望值

由对称性：

$$\langle x \rangle = 0, \quad \langle p \rangle = 0$$

### 8.4.2 位置平方和动量平方

$$\langle x^2 \rangle = \frac{\hbar}{2m\omega}(2n + 1)$$

$$\langle p^2 \rangle = \frac{m\hbar\omega}{2}(2n + 1)$$

不确定度：

$$\sigma_x = \sqrt{\frac{\hbar}{2m\omega}(2n + 1)}, \quad \sigma_p = \sqrt{\frac{m\hbar\omega}{2}(2n + 1)}$$

$$\sigma_x \sigma_p = \left(n + \frac{1}{2}\right)\hbar \geq \frac{\hbar}{2}$$

基态（$n = 0$）达到不确定关系的下限，是最小不确定态。

### 8.4.3 Virial 定理

对于势能 $V(x) \propto x^k$，Virial 定理给出：

$$\langle T \rangle = \frac{k}{2} \langle V \rangle$$

对于谐振子 $k = 2$：

$$\langle T \rangle = \langle V \rangle = \frac{E_n}{2}$$

这与经典结果一致：经典谐振子的平均动能等于平均势能。

## 8.5 与经典谐振子的对比

### 8.5.1 经典谐振子

经典谐振子 $x(t) = A\cos(\omega t)$，能量 $E = \frac{1}{2}m\omega^2 A^2$。

概率密度（在一个周期内某处找到粒子的概率）：

$$P_{\text{classical}}(x) = \frac{1}{\pi\sqrt{A^2 - x^2}}$$

在转折点 $x = \pm A$ 处最大（速度最慢），在中心 $x = 0$ 处最小（速度最快）。

### 8.5.2 量子-经典对应

量子概率密度 $|\phi_n(x)|^2$ 在 $n$ 较小时与经典结果截然不同：

- $n = 0$（基态）：高斯分布，中心最大
- $n = 1$：中心为零，两侧各有一个峰
- $n = 2$：三个峰，等等

但当 $n$ 很大时，量子概率密度在经典允许区内快速振荡，平均后趋于经典分布：

$$|\phi_n(x)|^2 \approx P_{\text{classical}}(x) = \frac{1}{\pi\sqrt{A^2 - x^2}}$$

其中 $A = \sqrt{2E_n/(m\omega^2)}$ 是经典振幅。

### 8.5.3 量子隧穿

即使在经典禁区（$|x| > A$），量子概率密度也不为零。粒子有一定的概率出现在经典不允许的区域。这是量子隧穿效应的又一体现。

## 8.6 三维谐振子

### 8.6.1 各向同性谐振子

三维各向同性谐振子的势能为：

$$V(r) = \frac{1}{2}m\omega^2 r^2 = \frac{1}{2}m\omega^2(x^2 + y^2 + z^2)$$

哈密顿量可以分解为三个独立的一维谐振子：

$$\hat{H} = \hat{H}_x + \hat{H}_y + \hat{H}_z$$

能量为：

$$E = \left(n_x + n_y + n_z + \frac{3}{2}\right)\hbar\omega = \left(N + \frac{3}{2}\right)\hbar\omega$$

其中 $N = n_x + n_y + n_z = 0, 1, 2, \ldots$

### 8.6.2 简并度

能级 $E_N$ 的简并度等于 $n_x + n_y + n_z = N$ 的非负整数解的个数：

$$g_N = \frac{(N+1)(N+2)}{2}$$

例如：
- $N = 0$：$g_0 = 1$（基态，非简并）
- $N = 1$：$g_1 = 3$（三重简并）
- $N = 2$：$g_2 = 6$（六重简并）

简并来源于系统的对称性（三维旋转对称性）。

## 8.7 应用实例

### 8.7.1 分子振动

双原子分子的振动可以近似为谐振子。约化质量 $\mu = m_1 m_2/(m_1 + m_2)$，力常数 $k$ 由分子势决定。

振动能级：

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega, \quad \omega = \sqrt{k/\mu}$$

红外吸收光谱中，分子吸收光子从 $n$ 跃迁到 $n+1$，吸收频率 $\nu = \omega/(2\pi)$。

### 8.7.2 晶格振动与声子

晶体中的原子在平衡位置附近振动。$N$ 个原子的晶体有 $3N$ 个振动模式（3个偏振方向，$N$ 个原子）。

每个振动模式等价于一个谐振子，能量量子化。振动的能量量子叫做**声子**（phonon）。

声子是凝聚态物理中最重要的概念之一，解释了固体的热容、热导、电导、超导等现象。

### 8.7.3 同位素效应

由于 $\omega \propto 1/\sqrt{\mu}$，不同同位素的分子振动频率不同。

例如，H₂O 和 D₂O（重水）的振动频率不同，导致物理化学性质的差异。

在超导中，同位素效应（$T_c \propto 1/\sqrt{M}$）是声子机制超导的关键证据。

## 本章小结

1. **能级**：$E_n = (n + 1/2)\hbar\omega$，等间距 $\hbar\omega$。

2. **零点能**：$E_0 = \hbar\omega/2$，是不确定关系的直接结果。

3. **波函数**：$\phi_n(x) \propto H_n(\xi) e^{-\xi^2/2}$，$H_n$ 是厄米多项式。

4. **Virial 定理**：$\langle T \rangle = \langle V \rangle = E_n/2$。

5. **最小不确定态**：基态达到不确定关系的下限。

6. **应用**：分子振动、声子、同位素效应。
