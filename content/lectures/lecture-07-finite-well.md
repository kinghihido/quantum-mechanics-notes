# 第7章 有限深势阱与隧穿

> **本章导读**：无限深势阱是一个理想化模型，真实的势阱总是有限深的。有限深势阱带来两个重要的新现象：一是波函数可以"渗入"经典禁区（隧穿效应），二是束缚态的数量有限（通常至少有一个）。这些现象在半导体物理、扫描隧道显微镜等技术中有直接应用。

---

## 7.1 有限深方势阱

### 7.1.1 势能函数

有限深方势阱定义为：

$$V(x) = \begin{cases} -V_0 & |x| < a \\ 0 & |x| > a \end{cases}$$

其中 $V_0 > 0$ 是阱深，$2a$ 是阱宽。

我们关心的是束缚态（$-V_0 < E < 0$），粒子主要被限制在阱内，但在阱外也有一定概率。

### 7.1.2 分区求解

**阱内**（$|x| < a$）：$V = -V0$，定态方程为：

$$-\frac{\hbar^2}{2m}\phi'' - V_0\phi = E\phi \quad \Rightarrow \quad \phi'' + k^2\phi = 0$$

其中 $k = \sqrt{2m(E+ + V_0)}/\hbar$。解为振荡函数：

$$\phi(x) = A\sin(kx) + B\cos(kx)$$

**阱外**（$|x| > a$）：$V = 0$，定态方程为：

$$-\frac{\hbar^2}{2m}\phi'' = E\phi \quad \Rightarrow \quad \phi'' - \kappa^2\phi = 0$$

其中 $\kappa = \sqrt{-2mE}/\hbar$（$E < 0$ 保证 $\kappa$ 为实数）。解为指数衰减：

$$\phi(x) = C e^{-\kappa|x|}$$

（取衰减支，因为 $|x| \to \infty$ 时波函数必须趋于零）

### 7.1.3 边界连接条件

在 $x = \pm a$ 处，波函数及其一阶导数必须连续：

$$\phi_{\text{in}}(\pm a) = \phi_{\text{out}}(\pm a)$$

$$\phi'_{\text{in}}(\pm a) = \phi'_{\text{out}}(\pm a)$$

这两个条件决定了能量 $E$ 的可能取值（本征值）。

### 7.1.4 偶宇称态

对于偶宇称态（$\phi(-x) = \phi(x)$），阱内取余弦解 $\phi = B\cos(kx)$。

在 $x = a$ 处连接：

$$B\cos(ka) = C e^{-\kappa a}$$

$$-Bk\sin(ka) = -C\kappa e^{-\kappa a}$$

两式相除：

$$k\tan(ka) = \kappa$$

这是**超越方程**，决定了偶宇称态的能量。

### 7.1.5 奇宇称态

对于奇宇称态（$\phi(-x) = -\phi(x)$），阱内取正弦解 $\phi = A\sin(kx)$。

类似地，在 $x = a$ 处连接得到：

$$k\cot(ka) = -\kappa$$

或等价地：\quad -k\tan(ka) = \kappa$

这是奇宇称态的超越方程。

### 7.1.6 图解法

超越方程无法解析求解，但可以用图解法。

定义无量纲变量 $z = ka$，$z_0 = a\sqrt{2mV_0}/\hbar$（表征势阱的"强度"）。

由 $k^2 + \kappa^2 = 2mV_0/\hbar^2$，得 $\kappa = \sqrt{z_0^2/a^2 - z^2}$。

偶宇称方程变为：

$$\tan z = \frac{\sqrt{z_0^2 - z^2}}{z}$$

作 $y = \tan z$ 和 $y = \sqrt{z_0^2 - z^2}/z$ 的图，交点即为解。

**关键结论**：
- $z_0 < \pi/2$ 时，只有一个偶宇称束缚态（基态）
- $z_0 > \pi/2$ 时，出现第一个奇宇称态（第一激发态）
- $z_0 > \pi$ 时，出现第二个偶宇称态
- 以此类推

**一维有限深势阱至少有一个束缚态**，无论阱多浅多窄。这是量子力学特有的现象（经典力学中，能量不够就无法束缚）。

## 7.2 隧穿效应

### 7.2.1 方势垒

考虑一个方势垒：

$$V(x) = \begin{cases} V_0 & 0 < x < a \\ 0 & \text{其他} \end{cases}$$

粒子能量 $E < V_0$（经典禁区）。

**经典预言**：粒子无法越过势垒，100% 反射。

**量子结果**：波函数在势垒内指数衰减，但不为零。如果势垒足够薄，波函数可以"穿透"势垒，在另一侧出现。这就是**隧穿效应**。

### 7.2.2 透射系数

求解定态薛定谔方程，，可以得到透射系数（透射概率）：

$$T \approx e^{-2\kappa a} = \exp\left(-\frac{2a}{\hbar}\sqrt{2m(V_0 - E)}\right)$$

（近似公式，适用于 $\kappa a \gg 1$）

透射系数随势垒宽度 $a$ 和高度 $(V_0 - E)$ 指数衰减。

### 7.2.3 隧穿的物理意义

隧穿效应是纯粹的量子现象，没有经典对应。它表明：

1. **粒子可以穿过能量上不可能越过的势垒**
2. **透射概率指数依赖于势垒参数**
3. **质量越小的粒子（如电子），隧穿效应越显著**

### 7.2.4 扫描隧道显微镜（STM）

STM 是隧穿效应最重要的应用之一。

**原理**：
- 金属探针与样品表面之间有一个纳米级的间隙（势垒）
- 加电压后，电子通过隧穿穿过间隙，形成隧穿电流
- 电流 $I \propto e^{-2\kappa d}$，其中 $d$ 是间隙宽度
- 间隙每变化 0.1 nm，电流变化约一个数量级

**特点**：
- 原子级分辨率（0.1 nm）
- 可以观察表面电子态
- 1986 年获诺贝尔物理学奖（Binnig 和 Rohrer）

### 7.2.5 α衰变

α衰变是核物理中的隧穿现象。

**模型**（Gamow, 1928）：
- α粒子在核内受到强相互作用（吸引）和库仑排斥
- 势能曲线形成一个势垒，高度约 20-30 MeV
- α粒子能量约 4-9 MeV，低于势垒
- 经典力学：α粒子无法逃出
- 量子力学：α粒子通过隧穿逃出

**半衰期**：

$$t_{1/2} \propto e^{2\kappa R}$$

其中 $R$ 是核半径，$\kappa = \sqrt{2m(V_0 - E)}/\hbar$。

由于指数依赖，势垒参数的微小变化导致半衰期的巨大差异（从纳秒到数十亿年）。

## 7.3 δ势阱与δ势垒

### 7.3.1 δ函数势

δ函数势是方势阱/势垒在宽度趋于零、高度趋于无穷时的极限：

$$V(x) = -\alpha \delta(x) \quad (\alpha > 0)$$

虽然数学上是理想化的，但δ势是极好的教学模型：计算简单，物理本质清晰。

### 7.3.2 δ势阱的束缚态

δ势阱 $V(x) = -\alpha\delta(x)$ 只有一个束缚态：

$$\phi(x) = \sqrt{\kappa} e^{-\kappa|x|}, \quad E = -\frac{m\alpha^2}{2\hbar^2}$$

其中 $\kappa = m\alpha/\hbar^2$。

注意：只有一个束缚态，且是偶宇称的。

### 7.3.3 δ势垒的散射

δ势垒 $V(x) = +\alpha\delta(x)$ 没有束缚态，但可以计算散射。

透射系数和反射系数为：

$$T = \frac{1}{1 + (m\alpha/\hbar^2 k)^2}, \quad R = \frac{(m\alpha/\hbar^2 k)^2}{1 + (m\alpha/\hbar^2 k)^2}$$

$T + R = 1$，概率守恒。

高能极限（$k \to \infty$）：$T \to 1$，粒子完全透射（势垒"消失"）。

## 7.4 WKB近似

### 7.4.1 适用条件

当势能 $V(x)$ 缓慢变化（相比德布罗意波长）时，可以用 WKB（Wentzel-Kramers-Brillouin）近似求解定态薛定谔方程。

### 7.4.2 WKB波函数

在经典允许区（$E > V$）：

$$\phi(x) \approx \frac{C}{\sqrt{k(x)}} \exp\left(\pm i \int k(x) dx\right), \quad k(x) = \frac{\sqrt{2m(E - V(x))}}{\hbar}$$

在经典禁区（$E < V$）：

$$\phi(x) \approx \frac{C}{\sqrt{\kappa(x)}} \exp\left(\pm \int \kappa(x) dx\right), \quad \kappa(x) = \frac{\sqrt{2m(V(x) - E)}}{\hbar}$$

### 7.4.3 隧穿概率

对于任意形状的势垒，WKB近似的透射系数为：

$$T \approx \exp\left(-\frac{2}{\hbar}\int_{x_1}^{x_2} \sqrt{2m(V(x) - E)} \, dx\right)$$

其中 $x_1, x_2$ 是经典转折点（$V(x_1) = V(x_2) = E$）。

对于方势垒，积分简化为 $\kappa \cdot a$，回到前面的结果。

### 7.4.4 玻尔-索末菲量子化条件

WKB近似还可以给出束缚态能量的近似公式。对于势阱中的束缚态：

$$\int_{x_1}^{x_2} p(x) dx = \left(n + \frac{1}{2}\right)\pi\hbar, \quad n = 0, 1, 2, \ldots$$

其中 $x_1, x_2$ 是转折点，$p(x) = \sqrt{2m(E - V(x))}$。

这就是**玻尔-索末菲量子化条件**（带 Langer 修正 $1/2$）。

对于无限深势阱，$x_1 = 0, x_2 = L, V = 0$：

$$pL = \left(n + \frac{1}{2}\right)\pi\hbar \quad \Rightarrow \quad E_n \approx \frac{(n + 1/2)^2\pi^2\hbar^2}{2mL^2}$$

与精确解 $E_n = n^2\pi^2\hbar^2/(2mL^2)$ 相比，大 $n$ 时近似很好。

## 7.5 共振隧穿

### 7.5.1 双势垒结构

考虑两个δ势垒构成的双势垒结构：

$$V(x) = \alpha[\delta(x + a) + \delta(x - a)]$$

在两个势垒之间形成一个"量子阱"。

### 7.5.2 共振现象

当入射粒子能量恰好等于量子阱的某个束缚态能量时，透射系数 $T = 1$（完全透射），尽管每个单独的势垒都会部分反射。

这就是**共振隧穿**，类似于光学中的法布里-珀罗干涉仪。

### 7.5.3 应用

共振隧穿在半导体器件中有重要应用：

- **共振隧穿二极管**（RTD）：利用共振隧穿实现负微分电阻
- **量子阱红外光电探测器**（QWIP）
- **超晶格结构**：周期性势垒中的共振隧穿导致能带形成

## 本章小结

1. **有限深势阱**：至少有一个束缚态；波函数渗入经典禁区。

2. **隧穿效应**：粒子可以穿过能量上不可能越过的势垒，透射概率指数依赖于势垒参数。

3. **δ势**：理想化模型，计算简单，物理本质清晰。

4. **WKB近似**：适用于缓变势场，给出隧穿概率和量子化条件的近似公式。

5. **共振隧穿**：双势垒结构中的完全透射现象，有重要应用。
