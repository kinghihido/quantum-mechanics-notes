# 第3章 康普顿散射与物质波

> **本章导读**：康普顿散射实验为光量子假设提供了最直接的证据——光子不仅具有能量，还具有动量，像台球一样与电子碰撞。但故事并没有结束。1924年，德布罗意提出了一个惊人的假设：既然光（波）具有粒子性，那么物质粒子（如电子）也应该具有波动性。这个大胆的假设很快被电子衍射实验证实，量子力学的革命由此进入新阶段。

---

## 3.1 康普顿散射实验

### 3.1.1 实验背景

1923年，康普顿（Arthur Compton）在研究X射线被物质散射时，发现了一个经典电磁理论无法解释的现象：散射X射线的波长比入射X射线长，而且波长的改变量与散射角有关。

按照经典电磁理论，入射电磁波使电子做受迫振动，振动的电子辐射出同频率的电磁波。因此，散射波的波长应该与入射波相同。但实验不是这样。

### 3.1.2 实验装置

康普顿的实验装置如下：

1. **X射线源**：发出单色X射线（波长 $\lambda$ 已知）
2. **散射靶**：石墨等轻元素（电子近似自由）
3. **探测器**：在不同散射角 $\theta$ 方向测量散射X射线的波长

实验发现：
- 散射X射线中，除了有与入射波长相同的成分（来自内层束缚电子），还有一个波长更长的成分
- 波长改变量 $\Delta\lambda = \lambda' - \lambda$ 随散射角 $\theta$ 增大而增大

### 3.1.3 光子-电子碰撞模型

康普顿用光子模型完美解释了这一现象。他把散射过程看作光子与自由电子的弹性碰撞：

**碰撞前**：
- 光子：能量 $E = h\nu = hc/\lambda$，动量 $\vec{p} = (h/\lambda)\hat{x}$
- 电子：静止，能量 $m_e c^2$，动量为零

**碰撞后**：
- 光子：能量 $E' = h\nu' = hc/\lambda'$，动量 $\vec{p}' = (h/\lambda')(\cos\theta\,\hat{x} + \sin\theta\,\hat{y})$
- 电子：能量 $E_e$，动量 $\vec{p}_e$

由能量守恒：

$$\frac{hc}{\lambda} + m_e c^2 = \frac{hc}{\lambda'} + E_e$$

由动量守恒（x方向和y方向）：

$$\frac{h}{\lambda} = \frac{h}{\lambda'}\cos\theta + p_{e,x}$$

$$0 = \frac{h}{\lambda'}\sin\theta - p_{e,y}$$

利用相对论能量-动量关系 $E_e^2 = (p_e c)^2 + (m_e c^2)^2$，经过代数运算，可以得到：

$$\Delta\lambda = \lambda' - \lambda = \frac{h}{m_e c}(1 - \cos\theta)$$

这就是**康普顿散射公式**。

### 3.1.4 康普顿波长

公式中的常数 $h/(m_e c)$ 具有长度的量纲，叫做**电子的康普顿波长**：

$$\lambda_C = \frac{h}{m_e c} = \frac{6.626 \times 10^{-34}}{9.109 \times 10^{-31} \times 3 \times 10^8} = 2.426 \times 10^{-12} \text{ m} = 0.0243 \text{ Å}$$

康普顿散射公式预言：
- $\theta = 0°$ 时，$\Delta\lambda = 0$（直进，无散射）
- $\theta = 90°$ 时，$\Delta\lambda = \lambda_C = 0.0243$ Å
- $\theta = 180°$ 时，$\Delta\lambda = 2\lambda_C = 0.0486$ Å（反散射，最大波长改变）

实验测量结果与理论预言完美符合。

### 3.1.5 康普顿散射的意义

康普顿散射实验为光量子假设提供了最直接的证据：

1. **光子具有动量**：$p = h/\lambda$。在碰撞过程中，光子像台球一样将部分动量转移给电子。

2. **能量-动量守恒在微观世界仍然成立**：康普顿用相对论性能量-动量守恒推导出的公式与实验完美符合。

3. **光的粒子性得到确认**：光电效应说明光子具有能量 $E = h\nu$，康普顿散射说明光子还具有动量 $p = h/\lambda$。光子是真正的"粒子"。

## 3.2 德布罗意物质波

### 3.2.1 德布罗意的洞察

1924年，法国王子路易·德布罗意（Louis de Broglie）在他的博士论文中提出了一个惊人的假设。他的推理如下：

自然界应该具有某种对称性。既然光（传统上被认为是波）具有粒子性，那么物质粒子（如电子、质子、原子）也应该具有波动性。

对于光子，能量和动量与频率和波长的关系为：

$$E = h\nu, \quad p = \frac{h}{\lambda}$$

德布罗意假设，对于任何物质粒子（静止质量 $m_0 \neq 0$），同样的关系也成立：

$$\nu = \frac{E}{h}, \quad \lambda = \frac{h}{p}$$

其中 $p = mv$ 是粒子的动量。这就是**德布罗意关系**，对应的波叫做**德布罗意波**或**物质波**。

### 3.2.2 德布罗意波长的计算

对于一个动量为 $p$ 的粒子，其德布罗意波长为：

$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

**例1：宏观物体的德布罗意波长**

一个质量 $m = 0.1$ kg 的网球，以 $v = 10$ m/s 运动：

$$\lambda = \frac{6.626 \times 10^{-34}}{0.1 \times 10} = 6.626 \times 10^{-34} \text{ m}$$

这个波长远小于任何可探测的尺度（原子核的尺度约 $10^{-15}$ m），因此网球的波动性完全可以忽略，它表现得像一个经典粒子。

**例2：电子的德布罗意波长**

一个动能 $E_k = 100$ eV 的电子：

$$p = \sqrt{2m_e E_k} = \sqrt{2 \times 9.109 \times 10^{-31} \times 100 \times 1.602 \times 10^{-19}} = 5.4 \times 10^{-24} \text{ kg·m/s}$$

$$\lambda = \frac{h}{p} = \frac{6.626 \times 10^{-34}}{5.4 \times 10^{-24}} = 1.23 \times 10^{-10} \text{ m} = 1.23 \text{ Å}$$

这个波长与X射线波长相当，与原子间距同数量级。因此，电子通过晶体时应该能观察到衍射现象。

**例3：热中子的德布罗意波长**

室温下（$T = 300$ K），热中子的平均动能 $E_k = \frac{3}{2}kT \approx 0.04$ eV：

$$\lambda = \frac{h}{\sqrt{2m_n E_k}} = \frac{6.626 \times 10^{-34}}{\sqrt{2 \times 1.675 \times 10^{-27} \times 0.04 \times 1.602 \times 10^{-19}}} = 1.8 \text{ Å}$$

这个波长也与原子间距相当，因此热中子衍射是研究晶体结构的重要手段。

### 3.2.3 德布罗意假设的物理意义

德布罗意假设的核心是**波粒二象性**：一切物质客体（光子和物质粒子）都同时具有波动性和粒子性。

- **粒子性**：能量 $E$、动量 $p$、质量 $m$，表现为局域的、离散的"颗粒"
- **波动性**：频率 $\nu$、波长 $\lambda$，表现为扩展的、连续的"波"

这两种看似矛盾的性质通过普朗克常数 $h$ 联系在一起：

$$E = h\nu, \quad p = \frac{h}{\lambda}$$

当作用量（能量×时间或动量×长度）远大于 $h$ 时，波动性可以忽略，经典粒子近似成立；当作用量接近 $h$ 时，波动性变得显著，必须用量子力学描述。

## 3.3 电子衍射实验

### 3.3.1 戴维森-革末实验

德布罗意的假设在提出时被认为是大胆的猜测，甚至他的答辩委员会都不太确定该不该通过他的博士论文。他们把论文寄给爱因斯坦，爱因斯坦大加赞赏。

1927年，戴维森（Clinton Davisson）和革末（Lester Germer）在美国贝尔实验室做了电子衍射实验，证实了德布罗意的假设。

他们用电子束轰击镍晶体表面，测量散射电子的角分布。他们发现：

- 散射电子强度随角度有明显的峰值和谷值
- 峰值位置与X射线衍射的布拉格公式一致，只需将X射线波长替换为电子的德布罗意波长

**布拉格公式**：

$$2d\sin\theta = n\lambda$$

其中 $d$ 是晶面间距，$\theta$ 是入射角，$n$ 是整数，$\lambda$ 是波长。

戴维森-革末实验测得的电子波长与德布罗意公式 $\lambda = h/p$ 的预言完全一致。

### 3.3.2 G.P. 汤姆孙实验

几乎同时，G.P. 汤姆孙（George Paget Thomson，J.J. 汤姆孙之子）独立做了电子衍射实验。他让电子束穿过金属薄膜，在后面的屏幕上观察到了衍射环——与X射线通过多晶样品产生的德拜-谢乐环完全类似。

有趣的是，J.J. 汤姆孙因为发现电子（粒子性）而获得1906年诺贝尔奖，G.P. 汤姆孙因为发现电子的波动性而获得1937年诺贝尔奖。父子两人，一个证实了电子的粒子性，一个证实了电子的波动性。

### 3.3.3 现代验证

此后，中子、质子、原子、甚至分子的衍射实验都成功了。1999年，维也纳大学的蔡林格（Anton Zeilinger）小组用 C₆₀ 富勒烯分子（60个碳原子，质量约 720 amu）做了双缝干涉实验，观察到了清晰的干涉条纹。

德布罗意假设已经经受了最严格的实验检验。

## 3.4 玻尔原子模型的回顾

### 3.4.1 玻尔模型的历史地位

在德布罗意提出物质波之前，玻尔（Niels Bohr）在1913年提出了他的原子模型。玻尔模型是量子论发展史上的重要里程碑，它成功解释了氢原子光谱。

玻尔的假设是：

1. **定态假设**：电子在某些特定的轨道上运动时，不辐射电磁波。这些轨道叫做定态。

2. **频率条件**：电子从一个定态（能量 $E_n$）跃迁到另一个定态（能量 $E_m$）时，发射或吸收一个光子，光子频率为：

$$\nu = \frac{|E_n - E_m|}{h}$$

3. **角动量量子化**：定态轨道的角动量必须是 $\hbar$ 的整数倍：

$$L = m_e v r = n\hbar \quad (n = 1, 2, 3, \ldots)$$

### 3.4.2 氢原子能级

根据玻尔模型，氢原子中电子的轨道半径和能量为：

$$r_n = n^2 a_0 \quad (n = 1, 2, 3, \ldots)$$

$$E_n = -\frac{13.6 \text{ eV}}{n^2} \quad (n = 1, 2, 3, \ldots)$$

其中 $a_0 = 0.529$ Å 是**玻尔半径**，$-13.6$ eV 是氢原子基态能量。

氢原子光谱的里德伯公式可以从玻尔模型推导出来：

$$\frac{1}{\lambda} = R_H \left(\frac{1}{m^2} - \frac{1}{n^2}\right)$$

其中 $R_H = 1.097 \times 10^7$ m⁻¹ 是里德伯常数，$m$ 和 $n$ 是正整数且 $n > m$。

### 3.4.3 玻尔模型的局限性

玻尔模型虽然成功解释了氢原子光谱，但存在严重的局限性：

1. **只能处理氢原子和类氢离子**：对于氦原子（两个电子），玻尔模型就无能为力了。

2. **无法解释谱线强度**：玻尔模型可以预言谱线的频率，但无法计算谱线的相对强度。

3. **无法解释精细结构**：氢原子光谱的某些谱线实际上是由靠得很近的几条线组成的（精细结构），玻尔模型无法解释。

4. **概念上的不自洽**：玻尔假设电子在定态轨道上不辐射，这违反了经典电动力学（加速的电荷应该辐射）。这是一个特设的假设，缺乏理论基础。

### 3.4.4 德布罗意对玻尔模型的解释

1924年，德布罗意为玻尔的角动量量子化条件提供了一个漂亮的物理解释。

德布罗意认为，电子的定态轨道对应于驻波。电子绕核运动一周，物质波必须自我相长干涉，否则波会相互抵消。这意味着轨道周长必须是波长的整数倍：

$$2\pi r = n\lambda \quad (n = 1, 2, 3, \ldots)$$

代入德布罗意关系 $\lambda = h/p = h/(m_e v)$：

$$2\pi r = n\frac{h}{m_e v}$$

整理得：

$$m_e v r = n\frac{h}{2\pi} = n\hbar$$

这正是玻尔的角动量量子化条件！

德布罗意的解释揭示了玻尔量子化条件的物理本质：**轨道量子化是因为驻波条件**。电子不是经典的粒子在轨道上运动，而是形成驻波的物质波。只有满足驻波条件的轨道才是允许的。

## 3.5 精细结构常数

### 3.5.1 定义与数值

精细结构常数 $\alpha$ 是量子力学和量子电动力学中最重要的无量纲常数之一：

$$\alpha = \frac{e^2}{4\pi\epsilon_0 \hbar c} = \frac{1}{137.036}$$

它结合了基本电荷 $e$、约化普朗克常数 $\hbar$、光速 $c$ 和真空介电常数 $\epsilon_0$，是电磁相互作用强度的度量。

### 3.5.2 物理意义

精细结构常数出现在量子力学的许多地方：

1. **氢原子能级的精细结构**：相对论修正和自旋-轨道耦合导致的能级分裂，量级为 $\alpha^2 E_n$。

2. **原子光谱的自然线宽**：激发态寿命与 $\alpha^3$ 成正比。

3. **量子电动力学的微扰展开**：任何量子电动力学过程的振幅可以按 $\alpha$ 的幂次展开，$\alpha \approx 1/137$ 是小量，因此微扰论非常有效。

### 3.5.3 石墨烯中的精细结构常数

精细结构常数不仅在原子物理中出现，在凝聚态物理中也有意想不到的表现。

石墨烯是单层碳原子排列成蜂窝状晶格的二维材料。石墨烯中的电子行为类似于无质量的狄拉克费米子，其"光速"不是 $c$，而是费米速度 $v_F \approx c/300$。

单层石墨烯对可见光的吸收率为：

$$A = \pi\alpha \approx 2.3\%$$

这是一个惊人的结果：吸收率只与精细结构常数有关，与波长无关（在可见光范围）。这是石墨烯作为"材料中的量子"的典型例子，我们将在后续章节中多次遇到。

## 3.6 从物质波到波函数

### 3.6.1 物质波的本质

德布罗意提出了物质波的概念，但"物质波到底是什么"这个问题并没有立即得到解答。

最初的候选者：
- **实在的波**：物质在空间中某种实在的振动？但电子是一个点粒子，什么是"振动的物质"？
- **引导波**：德布罗意本人提出的"导航波"（pilot wave）理论，认为粒子被一个引导波携带着运动。但这个理论过于复杂，且无法推广到多粒子体系。

最终的解答由玻恩（Max Born）在1926年给出：**物质波是概率波**。波函数的模方 $|\psi(\vec{r}, t)|^2$ 表示在时刻 $t$、位置 $\vec{r}$ 处找到粒子的概率密度。

这个诠释将在下一章详细讨论。

### 3.6.2 波函数的提出

薛定谔（Erwin Schrödinger）在德布罗意工作的基础上，于1926年提出了描述物质波演化的方程——**薛定谔方程**：

$$i\hbar\frac{\partial\psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi$$

这是量子力学的核心方程，地位相当于经典力学中的牛顿第二定律。我们将在第8章详细讨论薛定谔方程的建立和物理意义。

## 本章小结

1. **康普顿散射**证实了光子具有动量 $p = h/\lambda$，为光量子假设提供了最直接的证据。

2. **德布罗意物质波假设**：一切物质粒子都具有波动性，波长 $\lambda = h/p$，频率 $\nu = E/h$。

3. **电子衍射实验**（戴维森-革末、G.P. 汤姆孙）证实了电子的波动性。

4. **玻尔原子模型**的角动量量子化条件可以用驻波条件解释：$2\pi r = n\lambda$。

5. **精细结构常数** $\alpha \approx 1/137$ 是电磁相互作用强度的度量，在石墨烯中表现为普适的光吸收率 $\pi\alpha \approx 2.3\%$。

6. **波粒二象性**是量子力学的核心：一切物质客体都同时具有波动性和粒子性。
