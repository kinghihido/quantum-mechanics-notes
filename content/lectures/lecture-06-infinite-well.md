# 第6章 一维无限深势阱

> **本章导读**：现在我们有了薛定谔方程，接下来要解它。最简单的情况是一维无限深势阱——粒子被关在两面"不可穿透的墙"之间。这个模型虽然简单，却包含了量子力学最核心的特征：能量量子化、零点能、波函数的节点定理。它是理解一切束缚态问题的起点。

---

## 6.1 模型设定

### 6.1.1 势能函数

一维无限深势阱的势能函数为：

$$V(x) = \begin{cases} 0 & 0 < x < L \\ \infty & x \leq 0 \text{ 或 } x \geq L \end{cases}$$

粒子被限制在 $0 < x < L$ 的区域内，阱外波函数必须为零（否则能量无穷大）。

### 6.1.2 边界条件

由于阱外 $\psi = 0$，波函数在边界处必须连续：

$$\psi(0) = 0, \quad \psi(L) = 0$$

这是**边界条件**，是求解定态薛定谔方程的关键。

---

## 6.2 求解定态薛定谔方程

### 6.2.1 阱内方程

在阱内（$0 < x < L$），$V = 0$，定态薛定谔方程为：

$$-\frac{\hbar^2}{2m}\frac{d^2\phi}{dx^2} = E\phi$$

整理为：

$$\frac{d^2\phi}{dx^2} + k^2\phi = 0, \quad k = \frac{\sqrt{2mE}}{\hbar}$$

这是标准的简谐振动方程，通解为：

$$\phi(x) = A\sin(kx) + B\cos(kx)$$

### 6.2.2 应用边界条件

**边界条件 $\psi(0) = 0$**：

$$\phi(0) = A\sin(0) + B\cos(0) = B = 0$$

所以 $B = 0$，波函数简化为 $\phi(x) = A\sin(kx)$。

**边界条件 $\psi(L) = 0$**：

$$\phi(L) = A\sin(kL) = 0$$

由于 $A \neq 0$（否则波函数恒为零，没有物理意义），必须有：

$$kL = n\pi, \quad n = 1, 2, 3, \ldots$$

注意 $n \neq 0$（否则波函数恒为零），$n$ 也不能为负（否则波函数只是正 $n$ 的负值，物理上等价）。

### 6.2.3 能量量子化

由 $k = n\pi/L$ 和 $k = \sqrt{2mE}/\hbar$，得到能量：

$$E_n = \frac{\hbar^2 k^2}{2m} = \frac{n^2\pi^2\hbar^2}{2mL^2}, \quad n = 1, 2, 3, \ldots$$

能量只能取离散值，这就是**能量量子化**。$n$ 叫做**量子数**。

### 6.2.4 归一化波函数

波函数为 $\phi_n(x) = A\sin(n\pi x/L)$。由归一化条件：

$$\int_0^L |\phi_n|^2 dx = |A|^2 \int_0^L \sin^2\left(\frac{n\pi x}{L}\right) dx = |A|^2 \cdot \frac{L}{2} = 1$$

所以 $A = \sqrt{2/L}$，归一化波函数为：

$$\phi_n(x) = \sqrt{\frac{2}{L}} \sin\left(\frac{n\pi x}{L}\right), \quad n = 1, 2, 3, \ldots$$

---

## 6.3 结果分析

### 6.3.1 能级结构

能量 $E_n = n^2 \pi^2\hbar^2/(2mL^2) \propto n^2$。

**基态**（$n = 1$）：$E_1 = \pi^2\hbar^2/(2mL^2)$

**第一激发态**（$n = 2$）：$E_2 = 4E_1$

**第 $n$ 激发态**：$E_n = n^2 E_1$

能级间距 $\Delta E = E_{n+1} - E_n = (2n+1)E_1$，随 $n$ 增大而增大。

### 6.3.2 零点能

基态能量 $E_1 = \pi^2\hbar^2/(2mL^2) > 0$，这就是**零点能**。

为什么基态能量不为零？因为如果 $E = 0$，粒子静止，位置和动量都确定（$\Delta x = 0, \Delta p = 0$），违反不确定关系。

更准确地说：粒子被限制在 $0 < x < L$，位置不确定度 $\Delta x \sim L$。由不确定关系 $\Delta p \geq \hbar/(2\Delta x) \sim \hbar/L$，动能 $E_k \sim (\Delta p)^2/(2m) \sim \hbar^2/(2mL^2)$，与 $E_1$ 同数量级。

### 6.3.3 波函数的节点

波函数 $\phi_n(x) = \sqrt{2/L}\sin(n\pi x/L)$ 在阱内有 $n-1$ 个节点（零点）：

$$x = \frac{L}{n}, \frac{2L}{n}, \ldots, \frac{(n-1)L}{n}$$

**节点定理**：一维束缚态中，第 $n$ 个能级的波函数恰有 $n-1$ 个节点。能量越高，节点越多，波函数振荡越快。

这与弦振动的驻波完全类似：基频（$n=1$）没有节点，第一泛音（$n=2$）有一个节点，等等。

### 6.3.4 奇偶性

如果我们把坐标原点移到势阱中心（$-L/2 < x < L/2$），势能函数关于 $x = 0$ 对称。此时波函数有确定的奇偶性：

- $n$ 为奇数：$\phi_n(x)$ 是偶函数（关于 $x = 0$ 对称）
- $n$ 为偶数：$\phi_n(x)$ 是奇函数（关于 $x = 0$ 反对称）

这是**宇称**的体现，我们将在第12章详细讨论。

---

## 6.4 期望值与不确定度

### 6.4.1 位置期望值

$$\langle x \rangle = \int_0^L x |\phi_n|^2 dx = \frac{2}{L} \int_0^L x \sin^2\left(\frac{n\pi x}{L}\right) dx = \frac{L}{2}$$

这与对称性一致：势阱关于 $x = L/2$ 对称，所以平均位置在中心。

### 6.4.2 位置平方期望值

$$\langle x^2 \rangle = \frac{2}{L} \int_0^L x^2 \sin^2\left(\frac{n\pi x}{L}\right) dx = L^2\left(\frac{1}{3} - \frac{1}{2n^2\pi^2}\right)$$

位置不确定度：

$$\sigma_x = \sqrt{\langle x^2 \rangle - \langle x \rangle^2} = L\sqrt{\frac{1}{12} - \frac{1}{2n^2\pi^2}}$$

当 $n \to \infty$ 时，$\sigma_x \to L/\sqrt{12}$，这是经典均匀分布的结果。

### 6.4.3 动量期望值

$$\langle p \rangle = \int_0^L \phi_n^* \left(-i\hbar\frac{d}{dx}\right) \phi_n dx = 0$$

这与驻波的性质一致：驻波是向左和向右行波的叠加，平均动量为零。

### 6.4.4 动量平方期望值

$$\langle p^2 \rangle = \int_0^L \phi_n^* \left(-\hbar^2\frac{d^2}{dx^2}\right) \phi_n dx = \frac{n^2\pi^2\hbar^2}{L^2} = 2mE_n$$

这与 $E_n = \langle p^2 \rangle/(2m)$ 一致（阱内 $V = 0$，总能量就是动能）。

动量不确定度：

$$\sigma_p = \sqrt{\langle p^2 \rangle - \langle p \rangle^2} = \frac{n\pi\hbar}{L}$$

### 6.4.5 检验不确定关系

$$\sigma_x \sigma_p = \hbar\sqrt{\frac{n^2\pi^2}{12} - 1} \geq \frac{\hbar}{2}$$

对于基态 $n = 1$：

$$\sigma_x \sigma_p = \hbar\sqrt{\frac{\pi^2}{12} - 1} \approx 0.568\hbar > \frac{\hbar}{2}$$

满足不确定关系，且不是最小不确定态（最小不确定态是高斯波包）。

## 6.5 与经典结果的对比

### 6.5.1 经典粒子在势阱中

经典粒子在无限深势阱中以恒定速度来回反弹。概率密度均匀：

$$P_{\text{classical}}(x) = \frac{1}{L}$$

与能量无关。

### 6.5.2 量子-经典对应

量子概率密度 $|\phi_n(x)|^2 = (2/L)\sin^2(n\pi x/L)$ 在 $n$ 较小时与经典结果截然不同：

- $n = 1$：概率集中在中心
- $n = 2$：中心概率为零，两侧各有一个峰
- $n = 3$：三个峰，等等

但当 $n$ 很大时，$\sin^2(n\pi x/L)$ 快速振荡，在一个小区域内平均后趋于 $1/2$，所以：

$$|\phi_n(x)|^2 \approx \frac{2}{L} \cdot \frac{1}{2} = \frac{1}{L} = P_{\text{classical}}(x)$$

这就是**对应原理**：当量子数很大时，量子结果趋于经典结果。

### 6.5.3 对应原理的体现

对应原理在无限深势阱中有多方面体现：

1. **概率密度**：$n \to \infty$ 时，$|\phi_n|^2 \to 1/L$（经典均匀分布）

2. **能级间距**：$\Delta E/E_n = (2n+1)/n^2 \to 0$（$n \to \infty$），能级趋于连续

3. **辐射频率**：从 $n$ 跃迁到 $n-1$，辐射频率 $\nu = (E_n - E_{n-1})/h \approx 2nE_1/h$。经典粒子往返频率 $f = v/(2L) = \sqrt{2E/m}/(2L)$。两者在 $n \to \infty$ 时一致。

## 6.6 实际 applications

### 6.6.1 量子点

量子点是纳米尺度的半导体颗粒，电子在三个维度上都被限制。可以近似为三维势阱模型。

量子点的能级间距与尺寸 $L$ 的关系：$\Delta E \propto 1/L^2$。尺寸越小，能级间距越大，光学吸收和发射蓝移。这就是为什么不同尺寸的量子点发出不同颜色的光。

### 6.6.2 共轭分子中的π电子

线性共轭分子（如丁二烯、己三烯）中的π电子可以近似为一维势阱中的粒子。势阱长度 $L$ 约等于分子链长度。

吸收光谱的波长 $\lambda \propto L^2$。分子链越长，吸收波长越长（红移）。这与实验观察一致。

### 6.6.3 金属中的自由电子

金属中的价电子可以近似为三维势阱中的自由电子气。虽然实际金属的势场不是无限深势阱，但许多定性结论（如能级分立、费米能）可以从势阱模型得到。

---

## 本章小结

1. **能量量子化**：$E_n = n^2\pi^2\hbar^2/(2mL^2)$，$n = 1, 2, 3, \ldots$

2. **零点能**：$E_1 > 0$，是不确定关系的直接结果。

3. **波函数**：$\phi_n(x) = \sqrt{2/L}\sin(n\pi x/L)$，有 $n-1$ 个节点。

4. **节点定理**：第 $n$ 个能级的波函数恰有 $n-1$ 个节点。

5. **对应原理**：$n \to \infty$ 时，量子结果趋于经典结果。

6. **应用**：量子点、共轭分子、金属自由电子气。
