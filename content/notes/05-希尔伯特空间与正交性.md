# 希尔伯特空间、基矢与正交性

## 一、核心概念

**一句话**：希尔伯特空间是"所有合法波函数居住的、带内积的完备矢量空间"；态矢量 |ψ⟩ 是空间里的元素（矢量），波函数 ψ(x) 只是它在位置基下的坐标，基矢才是坐标系本身。

**生活化类比**：
- **空间**：希尔伯特空间 = 无限维的"函数世界"，里面每个点是一个函数（波函数）
- **矢量 vs 基矢**：矢量是空间里的箭头（元素）；基矢是坐标系（x̂, ŷ）——量子空间里是 {|ψₙ⟩}
- **ψ(x) = ⟨x|ψ⟩**：像 vₓ = v·x̂，波函数是态矢量沿"位置轴"的分量

## 二、原理 / 机制

### 1. 希尔伯特空间的四层定义

| 层 | 内容 | 物理意义 |
|---|---|---|
| ① 线性空间 | 函数可相加、可数乘 | ψ(x) 可看成无限维坐标 (ψ(x₁), ψ(x₂), …) |
| ② 内积 | ⟨φ|ψ⟩ = ∫φ*ψ dx | 有了长度、垂直、投影 |
| ③ 完备性 | 极限不跑出空间 | 数学自洽（物理上几乎不手动查） |
| ④ 合起来 | 希尔伯特空间 | 所有可归一化波函数居住的空间 |

### 2. 波函数是"基矢"吗？——不是，是矢量

| | 二维平面 | 量子态空间 |
|---|---|---|
| 矢量（元素） | 箭头 v | 态矢量 \|ψ⟩ |
| 基矢（坐标系） | x̂, ŷ | 能量本征态 {\|ψₙ⟩} 或位置本征态 {\|x⟩} |
| 坐标（分量） | vₓ = v·x̂ | ψ(x) = ⟨x\|ψ⟩ |

**关键**："波函数"一词有歧义——抽象态矢量是 |ψ⟩（本体），ψ(x) 是它在位置基下的**坐标画像**，二者是同一对象的不同表示。

### 3. 为什么"不同能量的本征态"自动正交（证明）

设 $\hat H|a\rangle = a|a\rangle$，$\hat H|b\rangle = b|b\rangle$，$a\neq b$。双面计算 ⟨b|H|a⟩：

- 从左边：⟨b|H|a⟩ = a⟨b|a⟩
- 从右边（厄米性 + 本征值实数 b* = b）：

$$\langle b|\hat H|a\rangle = \langle a|\hat H|b\rangle^* = (b\langle a|b\rangle)^* = b\langle b|a\rangle$$

两式相等 → (a − b)⟨b|a⟩ = 0，a ≠ b → **⟨b|a⟩ = 0**。∎

### 4. 正交性要分三种情况（常见误区）

| 情形 | 是否正交 | 说明 |
|---|---|---|
| 厄米算符**不同本征值**的本征矢 | ✅ 自动正交 | 上面证明；能量不同必正交 |
| 简并（同能量）本征矢 | ❌ 不自动 | 可用 Gram–Schmidt 正交化选出一组正交基 |
| 任意两个普通波函数 | ❌ 不一定 | ⟨Ψ₁\|Ψ₂⟩ ≠ 0 才对应"有概率重叠/跃迁" |

### 5. 为什么偏爱正交归一基

- 基矢两两正交 + 归一（⟨ψₙ\|ψₘ⟩ = δₙₘ）→ 展开系数直接等于投影：

$$|\Psi\rangle=\sum_n c_n|\psi_n\rangle, \qquad c_n = \langle\psi_n|\Psi\rangle$$

- 完备性 $\sum_n|\psi_n\rangle\langle\psi_n|=\hat 1$ → 任意态都能展开
- 位置基是连续版：⟨x\|x'⟩ = δ(x−x')，展开系数即 ψ(x)

## 三、实操 / 用法

- **判断两个态是否正交**：算内积 ⟨φ|ψ⟩，为 0 正交
- **求展开系数**：选定正交归一基后 cₙ = ⟨ψₙ|Ψ⟩，一个内积搞定
- **判断能否同时确定两个量**：正交的基矢对应可区分的测量结果（联系笔记 02 对易关系）
- **遇到简并**：先找一组正交简并基（施密特），再做展开计算

## 四、常见问题 / 坑

| 问题 | 原因 | 解决/理解 |
|---|---|---|
| "波函数是基矢" | 混淆元素与坐标系 | 波函数是空间里的矢量；基矢是 {|ψₙ⟩} 或 {|x⟩} |
| "所有波函数都正交" | 把"基矢正交"推广过头 | 只有厄米算符不同本征值的本征矢/同一组正交基内部才正交；一般态可以任意重叠 |
| ψ(x) 和 |ψ⟩ 分不清 | 没理解"坐标表示" | ψ(x) = ⟨x\|ψ⟩，是同一态在位置基下的画像 |
| 以为简并态也自动正交 | 忽略同本征值自由度 | 简并子空间内可任意组合，需施密特正交化 |
| 正交性证明里 b* 哪来的 | 忘记厄米本征值为实数 | 厄米性 → 本征值实数，才有 ⟨a\|H\|b⟩* = b⟨b\|a⟩ |
