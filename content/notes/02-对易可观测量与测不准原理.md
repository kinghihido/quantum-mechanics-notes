# 对易可观测量与测不准原理

> 最后更新：2026-09-11
> 所属课程：《材料中的量子与统计》

---

## 一、核心概念

**一句话**：两个可观测量的测量顺序不影响结果，就叫"对易"；数学上即对易子 [A, B] = AB − BA = 0。

**生活化类比**：
- **对易**：先戴帽子再戴围巾 ↔ 先戴围巾再戴帽子 → 结果一模一样（顺序无关）
- **不对易**：先穿袜子再穿鞋 ↔ 先穿鞋再穿袜子 → 结果完全不同（顺序敏感）

量子力学里"测量"也是一种操作，会扰动系统。两个测量操作能随便换顺序、互不干扰 → 对易；一换顺序结果就变 → 不对易。

---

## 二、原理 / 机制

### 1. 数学定义

- 可观测量 = 能测量的物理量（能量、位置、动量、角动量…），每个对应一个**厄米算符**
- 对易子：[A, B] = AB − BA
- **对易 ⇔ [A, B] = 0 ⇔ AB = BA**
- 不对易 ⇔ [A, B] ≠ 0（顺序敏感）

### 2. 物理意义

| | 对易 [A,B]=0 | 不对易 [A,B]≠0 |
|---|---|---|
| 本征态 | 存在**共同完备本征态基** \|a, b⟩ | 无共同本征态 |
| 能否同时精确测量 | ✅ 可以 | ❌ 不可以 |
| 测量顺序 | 先测谁结果一样 | 顺序影响结果 |
| 不确定性 | ΔA·ΔB ≥ 0 | 存在测不准关系 |

**核心逻辑**：测完 A 得到确定值后，系统仍处在 A 的本征态上；若 B 与 A 对易，B 的测量不破坏 A 的信息 → 两个量可同时确定。反之测量一个就"扰动"另一个。

### 3. 典型例子

- **对易**：氢原子 / 中心力场中 H、L²、Lz 两两对易 → 量子数 (n, l, m) 可同时确定
- **对易**：自由粒子 H 与动量 p 对易 → 能量与动量可同测（动量守恒）
- **对易**：自旋 S² 与 Sz 对易 → 总自旋与 z 分量可同时确定
- **不对易**：位置与动量 [x̂, p̂] = iℏ → 海森堡测不准原理

### 4. 海森堡测不准原理（不对易的代表）

$$[\hat{x}, \hat{p}] = i\hbar \implies \Delta x \cdot \Delta p \ge \frac{\hbar}{2}$$

---

## 三、实操 / 用法

- **判定能否同时确定两个量**：先算对易子 [A, B]，为 0 即可同时测，非 0 则存在测不准关系
- **找守恒量**：H 与某个量对易 → 该量守恒（如 H 与 p 对易 → 动量守恒）
- **定量子数**：氢原子中找与 H 对易的最大算符集 {H, L², Lz} → 完整量子数 (n, l, m)

## 四、常见问题 / 坑

| 问题 | 原因 | 解决/理解 |
|---|---|---|
| 对易就是"两个算符相等"吗？ | 混淆概念 | 不是。对易是 AB = BA（乘积可交换），两算符本身可以完全不同 |
| 直流电导与动态电导混用 | 两种普适电导不同 | 动态 σ = e²/4ℏ；直流 σ_dc = 4e²/πℏ（复习时重点区分） |
| 以为所有量都能同时精确测量 | 忽略不对易情形 | 只有对易的算符对才有共同本征态；位置动量永远测不准 |
| 测不准被误解为"仪器不够精" | 原理性限制 | Δx·Δp ≥ ℏ/2 是量子力学内禀性质，与测量技术无关 |
