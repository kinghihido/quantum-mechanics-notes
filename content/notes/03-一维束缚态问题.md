## 一、核心概念

**一句话**：把电子限制在一维势阱里，只有特定（分立）能量 E 能给出"两端都衰减"的物理解——能量量子化由此而来；本讲求解了三个能精确解出的势：无限深势阱、有限深方势阱、谐振子。

**生活化类比**：
- **束缚态**：像绳子拴住的小球，只能在有限范围里荡来荡去（能量取分立值）；**散射态**：像脱缰的球，能跑到无穷远（能量连续）。
- **节点定理**：能量越高的驻波"抖得越厉害"——第 n 个束缚态恰有 n−1 个节点，就像弦上驻波的波节数随谐波次数增加。

**三个可精确求解的势**（本讲主线）：

| 势 | 能级 | 关键特征 |
|---|---|---|
| 无限深势阱 | Eₙ = n²π²ħ²/2ma² | 波函数在阱壁为零，ψₙ = √(2/a) sin(nπx/a) |
| 有限深方势阱 | 超越方程 tan z = √(z₀²/z² − 1) | 波函数渗入禁区，能级低于无限深阱；至少 1 个束缚态 |
| 谐振子 | Eₙ = (n + ½)ħω | 等间距能级 + 零点能 ħω/2 |

## 二、原理 / 机制

### 1. 一维定态的一般性质（曾谨言 §3.1）

**定态方程的曲率判据**：ψ″ = −(2m/ħ²)(E − V)ψ

| 区域 | 条件 | ψ″ 与 ψ 的关系 | 解的行为 |
|---|---|---|---|
| 经典允许区 | E > V | 反号 | 弯向 x 轴 → 振荡（E−V 越大波长越短） |
| 经典禁区 | E < V | 同号 | 背离 x 轴 → 指数增长/衰减，物理解取**衰减解** |
| 转折点 | E = V | ψ″ = 0 | 两种行为在此衔接 |

**转折点 vs 节点（易混淆）**：转折点（E=V）处**只有 ψ″=0（拐点），ψ ≠ 0**——例：谐振子基态在转折点 ψ ≈ 0.61ψ_max；"不发散"靠禁区取衰减解实现，与 ψ 是否为零无关。真正 ψ=0 的是：节点（节点定理，ψ″ 一般≠0）、无限深阱壁（V=∞ 边界条件）、束缚态无穷远（归一化）。三类点位置一般不同。

**打靶法**（数值求本征值的思路）：从左侧禁区取衰减解作初值，试探能量 E 积分到右端。
- E 偏低 → 曲线弯曲不足，右端趋于 +∞
- E 偏高 → 多穿过一次 x 轴后趋于 −∞
- 只有本征值 E 让波函数在右端衰减到零

**束缚态 vs 散射态**（按 E 与 V(±∞) 的大小分）：

| | 束缚态 | 散射态 |
|---|---|---|
| 能量 | E < V(∞) | E > V(∞) |
| 波函数 | 可归一化 | 不可归一化 |
| 能谱 | 分立 | 连续 |
| 材料例 | 杂质能级、量子点能级 | 导带自由电子 |

**一维束缚态普遍定理**（不用求解即可判断，可检验数值解）：
1. **非简并**：每个能量只对应一个态
2. **实函数**：ψ 总可取为实函数
3. **确定宇称**：若 V(−x) = V(x)，则 ψ(−x) = ±ψ(x)
4. **节点定理**：第 n 个束缚态有 n−1 个节点（n = 1, 2, …）

**材料例子——硅中施主杂质（类氢模型）**：Si 掺 P，多余电子受 P⁺ 束缚。
- 质量换成有效质量 m* ≈ 0.26 m，库仑作用被介电常数 ε ≈ 11.7 削弱
- 束缚能实测：Sb 39 meV、**P 45 meV**、As 54 meV（模型 ~26 meV）
- 轨道半径 ~2.4 nm，覆盖上千个原子 → 晶体可视为连续介质
- 室温 kT ≈ 26 meV，施主几乎全部电离 → 提供导电电子
- GaAs：m* = 0.067 m、ε = 12.9，施主束缚能仅 ~6 meV

### 2. 无限深势阱（Griffiths §2.2 / 曾谨言 §3.2.1）

- **本征函数与能级**：ψₙ = √(2/a) sin(nπx/a)，Eₙ = n²π²ħ²/2ma²；宇称相对阱心交替
- **正交归一 + 完备性**：任意满足边界条件的函数可按 ψₙ 展开 = 傅里叶正弦级数
- **数量级**：电子 a = 1 nm → E₁ ~ 3.8 eV；a = 1 cm → E₁ ~ 10⁻¹⁵ eV 量级，量子化不可观测（ħ²/2m = 3.81 eV·Å²）
- **对应原理**：n 很大时概率密度振荡平均 → 1/a，能级相对间距趋于零 → 量子结果过渡到经典

**例：定态的平均值与不确定度（Griffiths 2.4）**
- ⟨x⟩ = a/2，⟨x²⟩ = a²/3 − a²/(2n²π²)；⟨p⟩ = 0，⟨p²⟩ = n²π²ħ²/a²
- Δx·Δp：n = 1 时为 0.568ħ，随 n 增大
- 讨论：定态 ⟨p⟩ = 0 但 ⟨p²⟩ ≠ 0 → 动能来自动量的涨落（先凭对称性判断哪些平均值为零）

**例：阱壁突然外移（a → 2a）**
- 初态来不及变化，仍为原基态，按新阱（宽 2a）本征态展开
- 测得原基态能量 E₁ 概率最大 |c₁|² = 1/2；|c₂|² ≈ 0.360、|c₃|² ≈ 0.120（n ≥ 4 的偶数项为零）
- 能量平均值仍为 E₁（初态能量守恒）

**例：初态 Ax(a−x)（Griffiths 例 2.2，课件 33–34 页）**
- 归一化：∫₀ᵃ x²(a−x)²dx = a⁵/30 → A = √(30/a⁵)（展开 a²x²−2ax³+x⁴ 逐项积分，或 Beta 函数 a⁵B(3,3)=a⁵/30）
- 展开系数：cₙ = 8√15/(nπ)³（n 为奇数），n 为偶数时 cₙ = 0（∫₀ᵃx(a−x)sin(nπx/a)dx = 4a³/(nπ)³·[1−(−1)ⁿ]）
- 能量分布：|c₁|² = 0.9986 占绝对主导；⟨H⟩ = Σ|cₙ|²Eₙ = 5ħ²/ma² = 1.013E₁
- 时间演化：Eₙ = n²E₁ → Ψ(x,t) 以 T = 2πħ/E₁ 为周期重复（准周期）
- 技巧：由对称性判断哪些系数为零；Σ|cₙ|² = 1 检验计算

**三维势箱与态密度（Griffiths §5.3）**
- E = (π²ħ²/2mL²)(n₁² + n₂² + n₃²)
- 简并：不同 (n₁,n₂,n₃) 可给相同能量，如 (2,1,1)、(1,2,1)、(1,1,2)
- 态密度：N(E) ∝ E^(3/2) → g(E) = dN/dE ∝ √E；二维为常数，一维 ∝ 1/√E
- 应用：自由电子气费米能、电子比热（第 19 讲）

**应用：量子阱激光器**
- GaAs 层夹在 AlGaAs 之间（~10 nm），导带/价带各成有限深势阱
- 发光能量 hν = E_g + e₁ + h₁，阱越窄发光波长越短
- 优点：态密度台阶形、载流子集中在带边 → 阈值电流低、温度稳定性好
- 阿尔费罗夫 & 克勒默因半导体异质结获 2000 年诺贝尔物理学奖

### 3. 有限深方势阱（Griffiths §2.6 / 曾谨言 §3.2.2）

**分区求解**：−a < x < a 内 V = −V₀，阱外 V = 0，束缚态 −V₀ < E < 0
- 阱内：cos kx（偶宇称）/ sin kx（奇宇称），k = √(2m(E+V₀))/ħ
- 阱外：取衰减解 e^(−κ|x|)，κ = √(−2mE)/ħ
- 连接条件：ψ、ψ′ 在 x = ±a 连续（V 有限跳变 → ψ′ 连续，由方程在跳变点两侧积分可证）

**匹配条件与图解法**：偶宇称要求 ψ′/ψ 连续 → 超越方程 tan z = √(z₀²/z² − 1)（奇宇称：−cot z 对应式）
- 无量纲量：z = ka，z₀ = a√(2mV₀)/ħ —— **z₀ 是唯一参数**
- 图解：tan z 与右端曲线 √(z₀²/z² − 1) 的交点即束缚态（z₀ = 8 时有 3 个偶宇称解）
- 奇宇称态存在条件：z₀ > π/2

**性质**：
- 无论多浅多窄，一维对称势阱**至少有一个束缚态**（三维球方势阱太浅则无）
- 束缚态数目由 z₀ 决定（z₀ = 4 → 3 个束缚态）
- 波函数以 e^(−κx) 渗入禁区，渗透深度 1/κ → 能级低于同宽无限深阱
- 极限：z₀ → ∞ 回到无限深势阱；z₀ → 0 只剩一个束缚态

**例：GaAs/AlGaAs 量子阱（10 nm，V₀ ≈ 0.3 eV，m* = 0.067 m）**
- z₀ ≈ 3.63（a = 5 nm）→ 3 个束缚态
- 有限深：e₁ ≈ 34、e₂ ≈ 132、e₃ ≈ 271 meV；无限深给出 56、224、505 meV（明显偏高）
- 有效质量：能带决定晶体中电子运动，用 m* 代替 m 后一维势阱模型仍适用
- 实验：光致发光谱 / 吸收谱测子带间隔 → 检验阱宽与界面质量

**有限差分法（数值方法）**
- 离散化：格点间距 Δ，用 (ψⱼ₋₁ − 2ψⱼ + ψⱼ₊₁)/Δ² 代替 ψ″
- 哈密顿量 → **三对角矩阵**：对角元 ħ²/m*Δ² + Vⱼ，相邻元 −ħ²/2m*Δ²
- 本征值 = 能级，本征矢 = 格点波函数（numpy 可解）
- 精度：误差 ∝ Δ²；GaAs 阱取 Δ = 0.25 nm（~250 格点）基态误差 < 0.1 meV

### 4. 一维谐振子（Griffiths §2.3 / 曾谨言 §3.4 / Sakurai §2.3）

**为什么处处是谐振子**：光滑势能在极小点附近展开 V ≈ ½mω²x²，小振动都可近似为谐振子。
- 分子振动（红外光谱）、晶格振动（声子）、电磁场模式（光子）、统计物理（爱因斯坦固体、黑体辐射）

**级数解法要点**：
- 无量纲化：ξ = x√(mω/ħ)，方程化为 ψ″ + (λ − ξ²)ψ = 0，λ = 2E/ħω
- 渐近行为：ξ → ∞ 时 ψ ~ e^(−ξ²/2)；令 ψ = h(ξ)e^(−ξ²/2)，h 满足 Hermite 方程
- 级数截断条件：λ = 2n + 1（否则 ψ 按 e^(+ξ²/2) 增长不可归一化）
- **结果**：Eₙ = (n + ½)ħω，ψₙ = Nₙ Hₙ(ξ) e^(−ξ²/2)（Hₙ 为 Hermite 多项式）

**能级与波函数特点**：
- **等间距**：间隔均为 ħω；第 n 激发态 = n 个能量 ħω 的量子
- **零点能**：E₀ = ħω/2；基态是最小不确定态 Δx·Δp = ħ/2
- **宇称与节点**：宇称 (−1)ⁿ，n 个节点；波函数渗出经典转折点外
- **大量子数**：|ψₙ|² 平均 → 经典分布 1/(π√(A²−x²))（转折点附近概率最大）
- **维里定理**：每个定态 ⟨T⟩ = ⟨V⟩ = Eₙ/2

**例：分子振动与同位素效应**
- ω = √(k/μ)，μ 为约化质量；能级间隔 ħω 对应红外吸收频率
- HCl：基频 2886 cm⁻¹，ħω ≈ 0.358 eV，力常数 k ≈ 480 N/m，零点能 0.179 eV
- 同位素效应：DCl 的 k 不变、μ 约增一倍 → 基频降为 2091 cm⁻¹（ω ∝ 1/√μ）
- 动力学同位素效应：X–H 键零点能高于 X–D → H 更容易断裂
- 非谐性：真实势非抛物线，高能级间隔减小 → Morse 势描述

**零点能的历史**：
- 普朗克（1911）"第二理论"：振子平均能量多出 hν/2
- 爱因斯坦 & 施特恩（1913）：用零点能讨论氢比热
- 马利肯（1924）：BO 分子硼同位素谱带位移 → 振动能量须取半整数量子
- 海森堡 & 薛定谔（1925–26）：量子力学直接给出 (n + ½)ħω

**晶格振动与声子**
- 简正坐标变换 → 一组独立谐振子，每个模式频率 ωₖ
- 声子：模式 k 处于第 nₖ 激发态 = 有 nₖ 个声子；总能量 Σₖ(nₖ + ½)ħωₖ
- 比热：高温每个振子平均 kT（杜隆–珀替）；低温高频模式不激发 → 比热下降
- 零点振动：T = 0 原子仍在振动，影响晶格常数、产生同位素效应
- 热导来自声子输运，热膨胀来自非谐性（声子统计在第 16 讲）

**红外光谱与拉曼光谱（材料表征）**
- 红外吸收：光子能量 = ħω 被吸收，要求振动引起**电偶极矩变化**（HCl 有、H₂ 没有）
- 拉曼散射：光子散射得失 ħω，频移 = 振动频率，**对称振动也可测**
- Si 拉曼峰 520 cm⁻¹，峰位随应力移动 → 测薄膜/器件应力
- 碳材料：金刚石 1332 cm⁻¹；石墨烯 G 峰 ~1580 cm⁻¹、2D 峰 ~2700 cm⁻¹ → 判断层数
- 拉曼 1928 年发现拉曼散射，1930 年诺奖

**黄昆与晶格动力学**
- 黄昆方程（1951）：长波光学振动与电磁场耦合 → **声子极化激元**
- 亨利 & 霍普菲尔德（1965）：GaP 拉曼散射测出极化激元色散关系
- 黄–里斯理论（1950）：晶体缺陷光跃迁的多声子理论
- 《晶格动力学理论》（与玻恩合著，1954）；黄昆 2001 年国家最高科学技术奖

**相干态**
- 基态高斯波包平移后释放 → 形状不变、中心像经典振子往返运动
- 不扩散原因：能级**等间距**，各分量相位按 ωt 整数倍变化，每周期精确复原（自由粒子波包会扩散）
- 任何时刻最小不确定（Δx·Δp = ħ/2），⟨x⟩、⟨p⟩ 满足经典运动方程
- 应用：激光场、微波腔、囚禁离子振动态（代数定义见第 8 讲）

## 三、实操 / 用法

- **判断解的行为**：看 E 与 V 的关系 → 允许区振荡 / 禁区指数衰减 / 转折点衔接
- **手算束缚态能级**：无限深阱直接代公式；有限深阱设 z、z₀ 画图找交点（或牛顿迭代）
- **数值求解任意势阱**：有限差分 → 三对角矩阵 → numpy 本征值（注意误差 ∝ Δ²）
- **判断束缚态数目**：算 z₀ = a√(2mV₀)/ħ，一维对称阱至少 1 个，个数由 z₀ 决定
- **材料表征**：振动能级用红外/拉曼光谱；子带间隔用光致发光/吸收谱

## 四、常见问题 / 坑

| 问题 | 原因 | 解决/理解 |
|---|---|---|
| 有限深阱能级和无限深阱差不多？ | 忽略了渗透 | 波函数渗入禁区使有效阱变宽 → 有限深能级**明显更低**（GaAs 例：34 vs 56 meV） |
| 以为一维阱可以有"无束缚态"的浅阱 | 与三维混淆 | 一维对称势阱无论多浅**至少 1 个束缚态**；三维球方阱太浅则无 |
| 谐振子基态能量"应该为零" | 经典直觉 | 量子基态 = ħω/2（零点能），且是最小不确定态，是普朗克 1911 年已提出的物理 |
| 定态 ⟨p⟩ = 0 就以为"没有动能" | 混淆平均值与涨落 | 动能 ∝ ⟨p²⟩ ≠ 0，来自动量涨落 |
| 认为 H₂ 也能红外吸收 | 忽略选择定则 | 红外吸收要求振动改变电偶极矩，同核双原子分子（H₂）无此效应，用拉曼测 |
| 量子化"应该总可观测" | 忽略尺度 | a = 1 cm 时能级间距 ~10⁻¹⁵ eV，量子化不可观测 → 对应原理接管 |
