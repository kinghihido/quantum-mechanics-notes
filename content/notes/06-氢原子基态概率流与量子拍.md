## 一、核心概念

**一句话**：单电子氢原子可以解析求解——用 1s 试探波函数 e^{-r/a} 做"系数匹配"，令 1/r 项消失即得玻尔半径 a₀=0.529 nm 和基态能量 E₁=−13.6 eV；多电子因库仑排斥无法分离变量（DFT 的动机）；含时方面，概率满足连续性方程 ∂ρ/∂t+∇·j=0，两定态叠加产生量子拍。

**生活化类比**：
- **系数匹配**：像配平化学方程式——要让 Hψ=Eψ 对每个 r 都成立，含 1/r 的"系数"必须恰好抵消
- **概率流**：概率像液体，只会流动不会凭空消失——某处概率减少的量恰好等于流走的量

## 二、原理 / 机制

### 1. 氢原子 1s 基态：从试探波函数到玻尔半径

**归一化 1s 波函数**：

$$\psi(r) = \frac{e^{-r/a}}{\sqrt{\pi a^3}}$$

（归一化常数来自 ∫|ψ|²4πr²dr = 1）

**代入哈密顿** $H = -\frac{\hbar^2}{2m}\nabla^2 - \frac{e^2}{4\pi\varepsilon_0 r}$，先算：

$$\nabla^2 e^{-r/a} = \left(\frac{1}{a^2} - \frac{2}{ar}\right)e^{-r/a}$$

整理得：

$$H\psi = \left[-\frac{\hbar^2}{2ma^2} + \left(\frac{\hbar^2}{ma} - \frac{e^2}{4\pi\varepsilon_0}\right)\frac{1}{r}\right]\psi$$

**系数匹配**：若 ψ 是本征态，Hψ=Eψ 须对所有 r 成立 → 1/r 的系数必须为零：

$$-\frac{e^2}{4\pi\varepsilon_0} + \frac{\hbar^2}{ma} = 0 \;\Rightarrow\; \boxed{a = \frac{4\pi\varepsilon_0\hbar^2}{me^2} = 0.529\ \text{nm}}$$

代回常数项得基态能量：

$$\boxed{E_1 = -\frac{\hbar^2}{2ma^2} = -\frac{e^2}{8\pi\varepsilon_0 a} = -13.6\ \text{eV}}$$

（Lecture3 第 7 页杂质能级、第 2 讲氢原子的基本参数来源）

### 2. 多电子：为什么必须近似（DFT 动机）

- 单电子：势能只有 -e²/(4πε₀r)，可分离变量、解析解
- 多电子：哈密顿多出**电子-电子库仑排斥**：

$$V_{ee} = \frac{e^2}{4\pi\varepsilon_0|\vec r_1 - \vec r_2|}$$

两个电子的坐标**耦合**在同一个项里 → 无法分离变量 → 无解析解 → 需要密度泛函理论（DFT）等近似方法

> ⚠️ 库仑排斥是 1/|r₁−r₂|（一次方）；积分测度是 dτ₁dτ₂ 双重积分

### 3. 概率流：概率守恒（连续性方程）

从含时薛定谔方程出发：ψ*×方程 + ψ×共轭方程，相加消去势能项：

$$i\hbar\left(\psi^*\partial_t\psi + \psi\,\partial_t\psi^*\right) = -\frac{\hbar^2}{2m}\left(\psi^*\nabla^2\psi - \psi\nabla^2\psi^*\right)$$

左边 = iℏ∂t|ψ|²；右边 = −(ℏ²/2m)∇·(ψ*∇ψ − ψ∇ψ*)。定义：

$$\rho = |\psi|^2, \qquad \vec j = \frac{\hbar}{2mi}(\psi^*\nabla\psi - \psi\nabla\psi^*)$$

得到**连续性方程**：

$$\boxed{\frac{\partial\rho}{\partial t} + \nabla\cdot\vec j = 0}$$

物理意义：概率守恒，与电荷守恒 ∂ρ_charge/∂t + ∇·j_charge = 0 同一数学结构。

### 4. 量子拍（两定态叠加，衔接笔记 04）

$$\psi(\vec r,t) = \frac{1}{\sqrt2}\left(\psi_1 e^{-iE_1 t/\hbar} + \psi_2 e^{-iE_2 t/\hbar}\right)$$

$$|\psi|^2 = \frac12\left[|\psi_1|^2 + |\psi_2|^2 + 2\psi_1\psi_2\cos\omega_{21}t\right], \qquad \omega_{21} = \frac{E_2-E_1}{\hbar}$$

交叉项给出余弦震荡——概率密度随时间拍动，拍频 = 能量差/ℏ。

## 三、实操 / 用法

- **求试探波函数的最佳参数**：代入 H → 整理成"常数项 + (含参数)1/r 项" → 令 1/r 系数为零（或对参数求极小）
- **写概率守恒**：由含时方程乘 ψ*/ψ 相加 → 定义 ρ、j → 得 ∂ρ/∂t+∇·j=0
- **算两态叠加的概率**：展开模平方，只留交叉项 e^{-iωt} 与其共轭 → 2cosωt

## 四、常见问题 / 坑

| 问题 | 原因 | 解决/理解 |
|---|---|---|
| 玻尔半径公式记混 | 系数多 | a₀ = 4πε₀ℏ²/me² = 0.529 nm；由"1/r 系数为零"推出，不用硬背 |
| 库仑排斥写成平方 | 手写/记忆误差 | 是 1/\|r₁−r₂\| 一次方；平方是错的 |
| 概率流方向搞反 | 符号 | j = (ℏ/2mi)(ψ*∇ψ−ψ∇ψ*)，m 在分母、i 前的符号定方向 |
| 以为单电子也需近似 | 混淆多电子 | 单电子氢原子是少数能精确解的问题；多电子才有库仑排斥耦合 |
| 归一化常数忘 √(πa³) | 只记 e^{-r/a} | ∫e^{-2r/a}4πr²dr = πa³，归一化后分母是 √(πa³) |
