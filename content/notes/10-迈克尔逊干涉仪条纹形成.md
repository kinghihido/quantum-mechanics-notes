# 迈克尔逊干涉仪：干涉条纹的形成

> 最后更新：2026-09-15
> 所属课程：《材料中的量子与统计》——波动光学

---

## 一、核心概念

**一句话**：干涉条纹不是"光程差"直接画出来的，而是**两束光叠加时相位差决定的明暗点在空间的排布**——光程差相同的点连成一条条纹。

**完整链条**：
```
光程差 Δ → 相位差 δ=2πΔ/λ → 两束光叠加 → 同相亮/反相暗 → 亮暗交替 = 条纹
```

**生活化类比**：两列水面波相遇，波峰撞波峰的地方浪更高（亮），波峰撞波谷的地方平静（暗）；"条纹"就是这些加强/减弱位置的集合。

---

## 二、原理 / 机制

### 1/ 光程差如何决定明暗

- 两束相干光在空间某点相遇 → 振动叠加
- 光程差 Δ → 相位差：δ = 2πΔ/λ
- **亮纹**：δ = 2mπ（Δ = mλ）→ 同相 → 振幅相加
- **暗纹**：δ = (2m+1)π（Δ = (m+½)λ）→ 反相 → 振幅相减

### 2/ 条纹的本质

光程差 Δ 随角度 θ 或位置连续变化。屏幕上每个点有各自的 Δ：
- Δ = 0, λ, 2λ… → 亮
- Δ = λ/2, 3λ/2… → 暗

**光程差相同的点，干涉结果相同，连成一条条纹**——条纹就是"等光程差线"。

### 3/ 迈克尔逊干涉仪具体化

M₂ 经分束器成的虚像 M₂′ 与 M₁ 构成**等效空气薄膜**，两臂光程差：

$$\Delta = 2d\cos\theta$$

| 情形 | 条件 | Δ 随什么变 | 条纹 |
|---|---|---|---|
| 等倾干涉 | M₁ ∥ M₂′（两镜严格垂直） | 只随出射角 θ | **同心圆环**（经典迈克尔逊条纹） |
| 等厚干涉 | M₁ 与 M₂′ 有微小夹角 | 随位置（空气隙厚度 d） | **平行直条纹**（等高线式） |

### 4/ 条纹移动 = 精密测长

- 移动 M₁（d 变化）→ 每个点的 Δ 都变 → 条纹整体移动
- **每移动一个条纹，M₁ 移动 λ/2**（Δ 变一个 λ ⇔ d 变 λ/2）
- 数条纹数 N → 位移 Δd = N·λ/2

---

## 三、实操 / 用法

- **测波长 λ**：已知位移 Δd，数条纹数 N → λ = 2Δd/N
- **测微小位移**：数条纹移动数 → Δd = N·λ/2
- **测折射率**：一臂插入介质，光程变化 (n−1)l 引起条纹移动

## 四、常见问题 / 坑

| 问题 | 原因 | 解决/理解 |
|---|---|---|
| 光程差怎么"变成"条纹？ | 缺了相位差环节 | 光程差 → 相位差 → 叠加明暗 → 相同 Δ 连成条纹 |
| 等倾为什么是圆环？ | Δ 只随 θ 变 | 相同 θ 的光（同一圆锥面）→ 相同 Δ → 同一圆环 |
| 等厚为什么是直条纹？ | Δ 随厚度位置变 | 厚度相同的线 = 等光程差线 = 直条纹 |
| 移动一个条纹 = 移动多少？ | Δ 与 d 的关系 | M₁ 移动 λ/2（Δ 变化一个 λ） |
| G₁/G₂ 的 45° 和公式的 θ 是一回事吗？ | 混淆两个角 | **不是**。45° 是玻璃板装配角（G₁ 分束、G₂ 补偿，固定不变）；公式 θ 是光线与空气薄膜法线的倾角（可变，等倾条纹的变量） |
| 为什么必须用相干光？ | 普通光相位随机 | 只有相位差恒定的两束光叠加才有稳定明暗分布 |
