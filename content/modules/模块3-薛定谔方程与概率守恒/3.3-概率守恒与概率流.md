# 3.3　概率守恒与概率流

> 模块3 · 薛定谔方程与概率守恒　|　状态：✅ 已通关（L2，§2.2.1；Slide 28–29；母题/题1/题2 已练）
> 来源：[课件L2逐页](../../01-课件/逐页MD/Lecture2.md) · [笔记07](../../03-课堂笔记/07-厄米性与内积守恒族证明.md)

## 速览

由薛定谔方程减其复共轭方程，得到连续性方程

$$\frac{\partial\rho}{\partial t}+\nabla\cdot\mathbf j=0,\qquad \rho=|\psi|^2,\qquad \mathbf j=\frac{\hbar}{2mi}\big(\psi^*\nabla\psi-\psi\nabla\psi^*\big)$$

总概率 $\int|\psi|^2d^3r$ 不随时间变：波函数一经归一化就始终归一化。概率流区分行波（$j=\rho v\neq0$）与驻波/束缚定态（$j=0$）。

## 精要

**推导方法**：用 $\psi^*$ 乘薛定谔方程，减去"复共轭方程乘 $\psi$"。

**总几率守恒**：取 $\psi_1=\psi_2=\psi$（内积守恒母题的特例），得 $d\!\int|\psi|^2d^3r/dt=0$。

**局部守恒（凑散度）**：展开 $\partial_t\rho=\partial_t(\psi^*\psi)=\psi^*\partial_t\psi+\psi\,\partial_t\psi^*$，代入薛定谔方程与复共轭，得

$$\frac{\partial\rho}{\partial t}=\frac{i\hbar}{2m}\big(\psi^*\nabla^2\psi-\psi\nabla^2\psi^*\big)$$

用乘积法则 $\nabla\cdot(f\nabla g)=\nabla f\cdot\nabla g+f\nabla^2g$，两式相减时交叉项 $\nabla\psi^*\cdot\nabla\psi$ 恰好抵消，凑成散度，对比 $\partial_t\rho+\nabla\cdot j=0$ 即得 $\mathbf j$。

**两个例子**：

- **平面波** $\psi=Ae^{i(kx-\omega t)}$：$\rho=|A|^2$，$j=|A|^2\hbar k/m=\rho v$，形式和经典流体相同。
- **实波函数**（束缚定态总可取为实函数）：$\psi^*=\psi$，两项相减 $j=0$。

隧穿电流（STM）正比于透射概率流，随针尖距离指数衰减；方势垒透射在模块6 计算。

## 例题（母题四步法，已通关）

**母题**：证明 $I(t)=\int\psi_1^*\psi_2\,d^3x$ 不随时间变。

1. 对 $t$ 求导，微分入积分号：$\dfrac{dI}{dt}=\int[\partial_t\psi_1^*\,\psi_2+\psi_1^*\partial_t\psi_2]d^3x$；
2. 薛定谔方程代入：$\partial_t\psi_2=\hat H\psi_2/(i\hbar)$，$\partial_t\psi_1^*=\hat H\psi_1^*/(-i\hbar)$（**第二项负号要显式写出**）；
3. 合并凑内积：$\dfrac{dI}{dt}=\dfrac{1}{i\hbar}[\langle\psi_1|\hat H|\psi_2\rangle-\langle\hat H\psi_1|\psi_2\rangle]$；
4. 厄米性两项相等 ⇒ $dI/dt=0$。∎

**题1 定态正交**：$\hat H\psi_1=E_1\psi_1$、$\hat H\psi_2=E_2\psi_2$，$E_1\neq E_2$，双面算 $\langle\psi_1|\hat H|\psi_2\rangle$ 得 $(E_1-E_2)\langle\psi_1|\psi_2\rangle=0$ ⇒ 正交。

## 易错点

- 第二项 $\partial_t\psi^*=\hat H\psi^*/(-i\hbar)$ **负号别丢**，否则相减不相消。
- 概率流 $j$ 的符号由连续性方程 $\partial_t\rho+\nabla\cdot j=0$ 定，别写反；$\hbar/2mi=-i\hbar/2m$。
- $\langle\psi_1|\psi_2\rangle$ 本身就是积分，终点别再套一个 $\int$。
- "偏导换成算符"换的是**偏导结果这个函数**（$\partial_t\psi\equiv\hat H\psi/i\hbar$），不是偏导符号本身；不是魔法。
