# 知识点目录约定（已按定稿模板执行）

## 命名

- 文件夹：`模块N-主题`，与《量子力学体系总览》的模块号一致。
- 文件：`N.小节号-名称.md`，小节号在模块内连续（如 `11.1-Ehrenfest定理.md`、`11.2-位力定理.md`）。
- 未学模块只建空文件夹，不提前写解释（留白，回来再补）。

## 单个知识点文件骨架（固定顺序）

1. **抬头**：模块、状态（✅已通关 / 📍引入 / ⏳进行中 / ⬜未学）、来源链接（旧笔记、答疑原文）。
2. **速览**：3–5 行，简单复习只看这里；含主公式。
3. **精要**：连贯段落讲清（不要一句一条碎列），公式随文，含"怎么理解/成立前提/失效条件"。
4. **相关知识点**：前置、并行、后置都挂可点击链接；目标点还没建的写"（待建点：…）"，拆到就接通。
5. **例题与完整推导**：完整题目 → 完整逐步推导 → ⚠️ 标出第一遍错处（复习重点，多多益善）。
6. **易错点汇总**。
7. **问答记录**：把对应答疑的成长点压成一条，原文留链接。
8. **留白**：以后聊到本点的新问答、新错题记这里。

## 来源与归并

- 课件逐页文字+公式见 `01-课件/逐页MD/Lecture1–4.md`（来源素材，不再复习长稿）。
- 旧长笔记（03-课堂笔记）、旧答疑（04-对话答疑记录）拆完后移入 `archive/` 保留，不删除；拆入的文件里保留原文相对链接。
- 讨论到哪个知识点，新问答直接追加进该文件的"问答记录/留白"。
