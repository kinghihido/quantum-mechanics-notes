# 量子力学学习网站 · v2.0.0

把《材料中的量子与统计》（量子力学部分）学透的一套**四支柱学习体系**。纯静态 HTML + Markdown，GitHub Pages 一键发布，全部内容可手动维护。

> 课程：北京大学 ·《材料中的量子与统计》（量子部分）
> 教材：曾谨言《量子力学·卷Ⅰ》为主，Griffiths 辅

## 四支柱

| 支柱 | 内容 | 文件 |
|---|---|---|
| ① 数学前备库 | M01–M56，九大类数学工具（线性代数/微积分/常微分/偏微分/傅里叶/复变/特殊函数/概率统计/数值方法），保证公式推导看得懂 | `content/math.md` |
| ② 量子力学概论 | 十章叙事长文，把整个课程串成一条逻辑线；公式全部不推导，只以编号链接跳转到图谱 | `content/overview.md` |
| ③ 公式图谱 | 蛛网交互页，F101–F200 编号；点公式节点弹出「可由哪些公式推出 / 可推出什么」，完整推导折叠展示 | `content/formulas.json` |
| ④ 例题精解 | 各模块纯例题集：先列「应用公式」链接清单，再按严谨答题规范分步求解 | `content/problems/` + `content/manifest.json` |

## 目录结构

```
quantum-mechanics-notes/

│   ├── overview.md         # 支柱② 量子力学概论（十章叙事）
│   ├── formulas.json       # 支柱③ 公式图谱数据（156 节点 / 96 边）

│   └── problems/           # 支柱④ 例题精解（模块4 已就位，其余陆续补）

```

## 更新方式

内容全部是 Markdown / JSON，直接改文件、提交推送即可，GitHub Pages 约 1 分钟自动发布。详见 [UPDATE.md](UPDATE.md)。
