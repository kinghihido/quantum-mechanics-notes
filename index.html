把量子力学学得数理分明

一门以数理逻辑为骨架的学习站：数学工具先行，公式推导成网，物理图景成文，例题可抄可对。四根支柱，互相链接。

支柱一

数学前备库 · M01–M56

线性代数、微积分、微分方程、傅里叶、特殊函数、概率统计、数值方法——56 条工具，保证任何推导看得懂；难懂条目点「补充」即见通俗披露。

 支柱二

量子力学概论

一支笔串起全部模块的流畅叙事：波粒二象、波函数、方程、束缚态、算符代数、对称与演化、谐振子与相干态。公式只给编号，不打断阅读。

 支柱三

公式图谱 · 001–200

可交互的推导蛛网：点开任意公式，看它由哪些公式推出、又能推出什么；应用公式到此为止。已亲自推导的边变绿加粗，点击可回看推导记录。

 支柱四

例题精解

每个模块一组可抄到答题纸的例题：先完整列出应用公式（带跳转），再按严谨答题规范分步求解。

推荐学习路径

  1. 扫一遍数学库（M01–M56），标记生疏的工具，用时回头查；
  2. 通读概论，不看公式细节，先把整个学科的因果链装进脑子；
  3. 进入任一模块的例题，动手算；卡在哪一步，就点公式跳进图谱看推导链；
  4. 回到概论，此时每一处链接都成了你踩过的路。

关于本学习站

本站在 v2.1.0 起支持：数学库条目「补充」块（难懂公式点开即见通俗披露）、公式图谱推导打卡（已亲自推导的边变绿加粗、点击回看推导记录）。自 v2.0.0 起改为"数理逻辑优先"的体系：数学工具（支柱一）→ 全局叙事（支柱二）→ 公式推导网（支柱三）→ 例题精解（支柱四）。

内容由作者自学《材料中的量子与统计》课程整理而成，供公开学习使用。公式若发现错误，欢迎指正。

技术：单文件 HTML + marked + KaTeX + ECharts，内容存放于 content/，静态部署于 GitHub Pages。
